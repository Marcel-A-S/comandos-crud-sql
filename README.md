# Atividade para prática de comandos CRUD no SQL

Neste repositório há exemplos de utilização dos comandos **CRUD**

-CREAD -> comando INSERT (inserir/cadastrar)
-READ -> comando SELECT (selecionar/consultar/obter/ler)
-UPDATE -> comando UPDATE (atualizar/editar/modificar)
-DELETE -> comando DELETE (deletar/excluir/remover)
